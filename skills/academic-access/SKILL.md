# 学术文献获取（说明，不是工具）

这里只写**怎么判断、各站什么脾气、登录态怎么管**。抓取动作全部交给 `super-fetch`，
遇到新站点照下面的模式类推，不要为单个站点写脚本。

## 总原则

1. **一律先知网**，中英文都是。知网不只是中文库：它收录外文期刊的**题录 + 中文摘要 +
   中文标题**，很多时候「这篇讲什么」在知网上几秒就能看明白，比翻出版商页面快得多；
   只是外文记录通常**没有全文下载入口**，要全文再走英文路线。
2. **能用网页抓到就不要写代码**。写死的脚本会在站点改版后变成负债，判断力不会。
   本 skill 不带任何脚本。
3. **每拿到一个文件先验真**：文件开头是 `%PDF` 才算拿到；名字叫 .pdf 但内容是 HTML 的，
   十有八九是被跳到了登录页或验证页。
4. **拿不到就明说**，不绕付费墙、不去盗版站。

## 中文文献：知网

- **检索**：`kns.cnki.net` 的检索页靠 JS 渲染，直接开浏览器模式最稳；
  也可以直接打列表接口 `kns8s/brief/grid`（POST，表单式参数）：
  - `boolSearch=true`、`QueryJson=<JSON>`、`pageNum`、`pageSize`、`dstyle=listmode`
  - `QueryJson` 里最关键的是 `QNode.QGroup[0].Items[0]`：`Field=SU`（主题）、`Value=<关键词>`、
    `Operator=TOPRANK`；`KuaKuCode` 是一串库代码（默认那串就够覆盖总库）
  - **`Rlang` 是外文开关**：写 `CHINESE` 会把外文全部过滤掉、返回「暂无数据」；
    要连外文一起搜，**留空**
  - **`pageSize` 只认 10 / 20 / 50**，给别的值会返回「字段【pageSize】校验失败」，
    看起来像「没数据」，其实是被拒了
  - 返回体是 HTML 表格，`no-content` 类名表示真的没有结果
- **外文文献**：结果里带「免费」角标的外文记录，打开后能看到**中文标题、中文摘要、
  作者机构、DOI**——写综述、判断这篇值不值得下，这些就够用了。
  但**记录页没有 PDF/CAJ 下载入口**，全文仍受出版商版权限制，要下还得回英文路线。
- **详情页地址必须从检索结果里原样复制**：里面带一个 `v=` 的加密串，自己拼不出来。
- **下载入口**是详情页里 `bar.cnki.net/bar/download/order?id=…` 那条链接，
  它会 302 到 `docdown.cnki.net` 再返回 PDF。
- **未登录时**这条链会跳 `login.cnki.net`，抓下来的是登录页 HTML——不是报错，
  很容易被当成「下载成功」，必须验文件头。
- 学位论文有 PDF 和 CAJ 两种，PDF 一般都有；2000 年前后的老论文是扫描件，
  文字层是乱码，需要 OCR 才有可检索文本。

## 英文文献

按这个顺序试，前一步拿不到再进下一步：

**1) 找到 DOI**
用 Crossref 的检索接口按标题或关键词查，只认 `journal-article`、`proceedings-article`、
`posted-content` 这几类；标题形如 `Figure 8: …`、`Table 1: …` 的是图注，不是论文。

**2) 查有没有免费版本**
用 Unpaywall 按 DOI 查，看它给的 `oa_locations`。
**仓储（repository）优先于出版商**：出版商站大多挂了 Cloudflare，机房 IP 一律 403；
arXiv、PMC、高校仓储通常直连就能下。

**3) arXiv**
CS / 物理 / 数学类先在这里找。它的标题检索是 **AND 语义**，整句丢进去零命中，
要取三四个最有区分度的词。**匹配到之后必须核对标题**：词集相似度低的时候容易抓到
另一篇论文，下发错文章比下发「没找到」更糟（实测踩过：
"Building a RAG Application" 被匹配成 "Engineering the RAG Stack"）。

**4) 出版商落地页**
打开 DOI 落地页，在 HTML 里找 `citation_pdf_url`——这是最可靠的 PDF 地址标记；
没有就找第一个 `.pdf` 链接。找到后直接抓那个地址。

**5) Wayback 存档（被挡时才用）**
用 `archive.org/wayback/available` 查有没有快照。取快照地址后把路径里的 `/web/<时间戳>/`
改成 `/web/<时间戳>if_/`，`if_` 不能省——不带它拿到的是 Archive 自己套的一层 HTML，不是原件。
存档站会限流（返 429），同一天不要对同一地址反复问。

## 各站点脾气（踩过的）

| 站点 | 情况 |
|---|---|
| 知网 kns.cnki.net | 检索页对无头浏览器 403，必须可见窗口；列表接口直连很快 |
| ACM dl.acm.org | 一律 403，但 Wayback 常有 PDF 快照，这条路最有效 |
| Elsevier / ScienceDirect | 订阅制，403 + 人机验证；**没有免费版就是没有**，存档里基本也没有 |
| IACR eprint | 页面能开、PDF 路径 403；Wayback 有存档 |
| MDPI / Wiley | 403 + Cloudflare；存档覆盖率低，多数救不回来 |
| arXiv | 直连最快（1–2 秒），优先用它 |
| PLOS / PMC | 直连可用，是仓库类里最稳的 |
| Google Scholar | **从这台机器走不通**：出口是机房 IP，每次「异常流量」验证码，自动化勾选无效。除非换家宽节点，否则别试 |
| 西南交大图书馆 | 有 ERA 校外访问（124 个库「智能访问」），但要读者证登录、约 7 天过期；主人已决定不走 |

## 登录态与 cookie 规则

- **什么时候要登录**：目标站点对匿名用户不给全文（知网、机构代理解析、部分出版商）。
  先匿名试，被跳登录页再登，不要一开始就登。
- **怎么存**：用 super-fetch 的交互登录模式（`--login`）在可见窗口里人工登录一次，
  会话按**域名命名**保存（如知网存 `cnki.json`）；之后访问同域名会自动匹配，不用每次指定。
- **cookie 要整包带上，不要挑单个键**。挑「看起来关键」的那一两个，是
  「明明登录了却拿不到数据」这类问题最常见的成因。
- **同名跨域去重取第一个**；值里有中文要 URL 编码（HTTP 头只吃 latin-1）。
- **会话文件是凭据**：权限 0600，不放仓库、不外发；要收回权限，退出登录或改密码即可。
- **过期判断**：知网会话约两周（当前这把到 2026-11-23）；学校身份类普遍只有 7 天。
  抓取连续失败且落地页是登录页时，先想到「会话过期了」，不要怀疑站点或代码。
- **登录窗口必须可见**：窗口默认甩到屏幕外的，人工登录时看不到，会以为卡住。
- 登录态只给自己用，不共享给第三方，也不写进任何会被上传的文件。

## 找书：优先 Z-Library（主人 2026-11-09 定）

**主人要书时，第一站是 Z-Library，不是论文那套流程。** 顺序：

| 顺位 | 站点 | 说明 |
|---|---|---|
| 1 | **Z-Library**（`z-lib.sk`） | **默认首选**。已有登录态，中文书覆盖最好（LibGen 没有的中文新书它常有）；下载入口 `/dl/<hash>` **必须用浏览器的 download 事件接住**——curl 是被 DiamWall 517 挡，普通抓取只拿到 HTML |
| 2 | Library Genesis（`libgen.li`） | Z-Library 没登录态/额度用完时用它；英文书命中率高，中文书库很小。`libgen.rs`／`libgen.is` 国内多不可达 |
| 3 | Anna's Archive（`annas-archive.gl`） | 聚合站兜底，常被 WAF 挡，人工浏览器更现实 |

LibGen 的用法要点：

- 检索：`libgen.li/index.php?req=<书名或 ISBN>`；**ISBN 检索最准**，中文书尤其
- 结果行里看 `Ext.`（pdf/epub/mobi）和 `Size`，点进去是 `ads.php?md5=<md5>` 页，
  页面上才有真正的下载链接 `get.php?md5=<md5>&key=<key>`
- **`ads.php` 必须带 `Referer: https://libgen.li/`**，否则直连会失败（实测 000/无响应）
- 同一本书常有多条（不同版本/扫描/转换版）：优先 **PDF + 页数合理 + 非扫描** 的那条
- 下载后验：`file` 看真实格式（.pdf 也可能是 HTML）、PDF 用 `pdfinfo` 看页数、
  epub 可以直接改名 unzip 看目录结构是否正常

中文书提示：LibGen 的中文库存远小于英文；**查不到就换 Z-Library**（实测《李大霄投资战略》第三版就是这样拿到的）。

Z-Library 实操要点（2026-11-08 实测）：

- 检索页的结果是自定义元素 `z-bookcard`，属性里直接写着 `href`（详情页）、`download`（`/dl/<hash>`）、
  `extension`、`filesize`、`isbn`、`year` —— 不用点开就知道是不是你要的那版
- **`/dl/<hash>` 只能由浏览器触发下载**：curl 带全套 cookie 也是 517；浏览器里 Playwright 会报
  `Download is starting`，必须在 `expect_download()` 里接住再 `save_as()`，否则存下的是 HTML
- 下完验：`pdfinfo` 看标题/作者/页数是否对得上，`pdftotext | wc -c` 判断有没有文字层（0 就是扫描件）

## 最后手段：影子库（2026-11-08 实测，**只作兜底**）

合法路径（知网 → Unpaywall/仓储 → arXiv → 出版商页 → Wayback）全部走空、且用户明确要时，
可以试影子库。**先问用户**，因为它们不稳定、且不属于正规授权渠道。

| 站点 | 现状 | 判断要点 |
|---|---|---|
| Sci-Hub（`.se` / `.st` / `.ru`） | `.se` 在国内连不上；`.st` 常 403；`.ru` 会跳 `.jp` | 命中时会返回 `<embed type="application/pdf">` 的直链；查不到就明确写「この論文は…利用できません」 |
| Library Genesis（`libgen.li`） | 可访问，但它**把 Crossref 的题录全量同步了** | **一定先看“Files”列**：题录有、文件栏空 = 只有元数据，没有 PDF（这就是最容易误判的地方） |
| Anna's Archive | 聚合 SciDB + LibGen，覆盖面最广 | 有 WAF，自动化基本过不去；人工浏览器打开更现实 |
| Z-Library | **官方域名 `z-lib.sk`**（2026-11-08 主人确认） | 有 DiamWall 反爬：curl 直连返 **517 Access Denied**，必须走浏览器模式；**登录后每日下载额度才高**，未登录几乎下不了几本 |

关键经验：

- **影子库的收录在 2021 年后断崖**。当年被起诉、新文入库基本停止，所以 **2022 年之后的新论文，
  命中率极低**——今晚拿一篇 2024 年的 Elsevier 文章试，Sci-Hub 明说没有、LibGen 只有题录。
- **“查到题录”不等于“拿到文件”**。LibGen 的搜索结果里，`Edition` 行有标题/DOI、但没有 Files，
  这是空壳。别看到标题就以为成了。
- **下载下来的文件必须验**：开头是 `%PDF`、页数合理、`pdftotext` 首段标题和你要的对得上。
  影子库返回 HTML 错误页、或者别人上传的错文件都很常见。
- **不绕人机验证**：遇到 ALTCHA、Cloudflare、reCAPTCHA 就停下，不要为了进去写脚本。
  （这条是硬的。）
- 不装任何“下载器”客户端；账号只用主人自己在可见窗口里登。
- **Z-Library 要登录态**：主人 2026-11-08 说会亲自登录一次，按 cookie 规则存成
  `zlib.json`（域名 `z-lib.sk`，之后自动匹配）。登录后额度高，但**别把会话文件外传**。

## 失败特征对照

| 现象 | 含义 | 下一步 |
|---|---|---|
| 403 + 几 KB 的 HTML | Cloudflare 挡机房 IP | 走 Wayback；再没有就换网络 |
| `Just a moment` / `Verifying` / 「异常流量」 | 人机验证，自动化过不去 | 停，换 IP 或让用户手动 |
| 200 但正文是空的/只有页脚 | 抓到的是壳页或页脚容器 | 换浏览器模式，或加长等待 |
| 正文只有一排 `word` | 骨架屏还没渲染完 | 等几秒再抓 |
| 文件叫 .pdf 但内容是 HTML | 被跳登录页/验证页 | 先登录；或换下载入口 |
| Wayback 返 429 | 存档站限流 | 隔几分钟；当天别重复问同一地址 |

## 什么时候该停

- 英文路线走到第 5 步仍没有 PDF、落地页也没有 → 直接告诉用户「这篇没有免费版」。
- 不为了拿到它去试盗版站、不绕付费墙、不伪造机构身份。
- 批量要 5 篇以上时先问用户：出版商和 Archive 都会限流。

## 用户偏好（2026-11-08 主人明确）

- **顺序：先知网，知网没有才走英文**。
- 文献统一放 `~/papers/`，发给用户时文件名要能看出「年份 + 标题」。
- 西南交大这条路不走（要读者证、7 天过期）。
- Google Scholar 不自动化（IP 被标记）。
- 已核对过的文献：CanDID（IEEE S&P 2021，IACR eprint 2020/934），存
  `papers/CanDID_IEEE_SP2021_原文.pdf`。
